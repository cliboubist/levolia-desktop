# Security dependency updates — 22 October 2026

The audit branch upgrades Electron from 40 to the maintained 43 branch, simple-git to 4.0.2 (including argv-parser 2.0.1), shell-quote and the affected Python dependencies. simple-git 4 uses a named ESM export; its consumer was adapted. Python security floors retain parent compatibility and upper bounds; uv.lock is regenerated with hashes.

## Release prerequisites

- A signed/notarized application must be rebuilt and tested on macOS and Windows before distribution. This PR does not publish binaries.
- At the last official release check, Electron 43.8.3 bundles Node 24.22.0, below the 24.22.1 fix for the 21 October Node advisories. Updating Electron here fixes other known Electron advisories but does not claim to resolve those embedded Node CVEs. Select an official stable containing the corrected Node runtime before release and verify process.versions in the final signed artifact.
- The optional OTLP/Mistral dependency set still pins OpenTelemetry API 1.39.1. GHSA-xcq7-p3pf-p88h is a remaining medium advisory: its 1.45.1 fix requires a coordinated Mistral/OTLP dependency migration. The resolver rejects a partial bump, so no parent constraints were overridden.

## Validation

Desktop TypeScript and production build passed. The existing git-review operations tests pass against simple-git 4. The combined git/hardening run has one pre-existing source-shape assertion failure: hardening.test.ts looks for a coercion call in the first 400 characters of the apply IPC handler, which now delegates to an existing helper. main.ts and this test are unchanged by this PR. The helper does perform coercion. MCP serve/OAuth Python regressions: 103 passed using scripts/run_tests.sh. No complete signed runtime E2E was run.

Treat the PR as a draft until runtime/native validation and the embedded Node release prerequisite are met.
